# Puerta de preparación para vídeo largo

La skill heredada `long-form-video` permanece intacta y fuera del flujo V2. No
se adaptará de forma especulativa porque contiene patrones, proyectos e
identidad de otro sistema.

La adaptación solo comienza cuando exista un caso real con:

- objetivo, audiencia y plataforma;
- formato y duración aproximada;
- guion, audio o estructura suficientemente definidos;
- material de María disponible;
- CTA;
- referencia y aspectos concretos a conservar;
- un fragmento piloto de 60–90 segundos;
- aprobación del brief y del storyboard del piloto.

Primero se construirá el piloto como proyecto nuevo. Solo sus patrones
aprobados podrán convertirse después en una skill `maria-long-form-production`.

No se invoca `long-form-video` para una producción de María.
