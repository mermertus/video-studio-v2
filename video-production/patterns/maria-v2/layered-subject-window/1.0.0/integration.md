# Integración

Copiar estas capas a `index.html` y conservarlas como hermanas en la raíz.
Mantener idénticos `object-position`, escala, crop y ventana temporal en el vídeo
base y el alfa. Sustituir todos los placeholders. No usar el fragmento como
subcomposición.

Los captions permanecen por encima del recorte y fuera de la cara. Verificar el
intervalo con una ráfaga temporal corta. Ante el primer fallo de bordes, aplicar
el fallback del registro.
