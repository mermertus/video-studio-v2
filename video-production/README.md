# Maria Video Production

Sistema de produccion de video/HyperFrames adaptado a la marca Maria Bejarano.

## Como usarlo

1. Entra en `video-production/`.
2. Lee `CLAUDE.md`, `DESIGN.maria-brand.md` y `MOTION_PHILOSOPHY.md`.
3. Para un proyecto nuevo, clona `video-projects/_maria-template/`.
4. Crea un `BRIEF.md` con objetivo, formato, audio, assets y CTA.
5. Trabaja desde dentro del proyecto.
6. Ejecuta preview, lint, draft render y QA visual antes del final.

## Carpetas clave

- `.claude/skills/`: skills clonadas/adaptadas desde Maria Bejarano.
- `assets/maria-tokens.css`: tokens de marca para composiciones.
- `video-projects/_maria-template/`: template base.

## Regla

El sistema tecnico viene de Maria Bejarano. La identidad final es Maria Bejarano.
