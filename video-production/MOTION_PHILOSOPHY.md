# Motion Philosophy - Maria Brand

Objetivo: producir videos de marketing que capten rapido, expliquen con criterio y empujen accion sin sonar a agencia generica.

## 0. Leyes

1. Una idea por beat.
2. Captar en menos de 3 segundos.
3. El movimiento sirve a conversion, no a decoracion.
4. El fondo respira: claro, azul claro o editorial.
5. El Merlot se reserva para la decision.
6. Los datos necesitan contexto: punto de partida, periodo, decision y resultado.
7. Las capturas y mockups entran para demostrar, no para rellenar.
8. La presencia de Maria se protege: rostro legible, titulares en zona segura.
9. El texto debe leerse en movil.
10. Ningun render se entrega sin preview, frame-check y QA visual.
11. El ritmo espacial no sigue un péndulo automático: combinar apoyo arriba, apoyo abajo, recurso a pantalla completa y `pip-llamada` según la idea.
12. Todo vídeo abre con un hook textual literal acompañado de un hook visual creado; el primer punto de una lista nunca sustituye al hook.
13. Todo hook lleva al menos un sticker o ilustración real con silueta propia. Puede usar movimiento tipo GIF si es finito, determinista y funcional.

## 1. Energia

Maria no es una marca lenta, pero tampoco grita.

- Entrada de titulares: directa.
- Movimiento de apoyo: medido.
- Transiciones: limpias, con intencion.
- Cierres: claros y con pausa suficiente para entender el CTA.

## 2. Transiciones aprobadas

- CSS Cover: para cambios de bloque con seguridad.
- CSS Push: para secuencias educativas o pasos.
- CSS Dissolve: para cambios suaves de idea.
- Blur Crossfade: para cierre, CTA o recap.
- Cinematic Zoom: solo en hooks, datos fuertes o cambio de escala.
- Light Sweep / Shimmer: muy puntual para destacar dato o palabra.
- Split-screen panel reveal: para coexistencia de talking-head + grafico.
- Full-screen visual reveal: para ocultar temporalmente a Maria y dar protagonismo total a un grafico, captura, b-roll o mockup, siempre con zona de subtitulos reservada.
- V2 protagonist sticker: obligatorio en el hook y disponible para énfasis intercalados. En el hook va grande, por delante de la imagen y con impacto claro para parar el scroll. En el cuerpo, la mayoría de stickers relevantes se colocan detrás de cabeza/cuerpo con recorte o máscara cuando el plano lo permite. Entra con `pop`/escala, rotación leve o `wiggle` corto en `0,35–0,65 s`, SFX sincronizado, sin tapar cara ni texto. Una tarjeta o panel no cuenta como sticker.
- PIP llamada / WhatsApp: para reducir a Maria desde plano principal hacia una ventana abajo a la derecha mientras el grafico toma protagonismo. Duracion `0,45–0,65 s`, sin bounce, con SFX `whoosh-tuck` sincronizado al momento en que la ventana encaja.

## 3. Transiciones a evitar por defecto

- Glitch.
- Neon/cyberpunk.
- Swirl exagerado.
- Bounce/spring jugueton.
- Destruccion si no hay una idea de ruptura real.

## 4. Pacing

- Short/Reel: beats de 1.0s a 2.5s.
- Explainer: beats de 2.0s a 5.0s.
- VSL/long-form: ritmo guiado por audio, con cambios visuales cada 4-8s.
- CTA final: mantener 2-5s segun duracion total.
- No repetir arriba/abajo de forma mecánica. Una secuencia puede ser `abajo → completo → pip-llamada → arriba`, `arriba → completo → abajo` u otra combinación motivada por el contenido.

## 5. Checklist

- [ ] Hook claro en los primeros 3 segundos.
- [ ] El hook textual literal aparece antes de cualquier enumeración y está acompañado por un sticker/ilustración real grande, frontal y con SFX.
- [ ] Los stickers del cuerpo, si aparecen, priorizan integración detrás de cabeza/cuerpo con recorte o máscara sin tocar subtítulos.
- [ ] Cada numeral empieza un caption nuevo y no comparte bloque con la frase anterior.
- [ ] Cada cambio de fondo, layout o fase se revisa un fotograma antes, en el límite y un fotograma después.
- [ ] Una idea principal por escena.
- [ ] Merlot usado como decision, no como decoracion.
- [ ] Azul sostiene continuidad visual.
- [ ] Captions legibles en movil.
- [ ] Nada tapa el rostro si Maria aparece.
- [ ] La secuencia combina formatos sin vaivén predecible.
- [ ] En los recursos a pantalla completa, Maria queda oculta y los subtitulos no pisan informacion esencial.
- [ ] En `pip-llamada`, Maria conserva proporción dentro de una ventana abajo derecha y ningún subtitulo pisa esa ventana.
- [ ] Capturas/mockups aportan prueba o contexto.
- [ ] No parece plantilla generica.
- [ ] Timeline HyperFrames llena su slot.
- [ ] Preview + draft + frame-check antes de final.
- [ ] No hay cartulinas ambiguas casi a pantalla completa: el recurso es completo o claramente compacto/dividido.
- [ ] Ningún panel tapa cara o cuerpo dejando restos inútiles de vídeo.
- [ ] Los textos pequeños o medios sobre metraje, foto, captura o b-roll complejo tienen base local sólida/semitransparente o contraste `4.5:1` verificado en frames.
- [ ] Ningún subtítulo cubre la boca; la primera línea queda bajo la barbilla.
- [ ] El cierre no contiene titulares sueltos que compitan con la CTA o la follow card.
