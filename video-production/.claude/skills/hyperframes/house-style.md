# House Style - Maria Brand Video

## Motion Speed

- Entrance: 0.25s-0.55s, directo.
- Transitions: 0.35s-0.75s, limpias.
- Exit: normalmente lo maneja la transicion de escena.
- CTA hold: 2s-5s segun duracion total.

## Approved Transitions

- CSS Cover.
- CSS Push.
- CSS Dissolve.
- Blur Crossfade.
- Cinematic Zoom, solo para hooks o datos fuertes.
- Split-screen panel reveal.
- Light sweep puntual.

## Typography Motion

- Titulares: Source Serif 4.
- Cuerpo/captions: Work Sans.
- Labels/datos: IBM Plex Mono.
- Highlight: Merlot, una zona por pantalla.

## Visual Layers

- Talking head protegido.
- Capturas/mockups cuando aportan prueba.
- Anotaciones finas.
- Lineas y subrayados funcionales.
- Graficos simples y legibles.

## Avoid

- Glitch por defecto.
- Neon.
- Bounce/spring jugueton.
- Paletas fuera de marca.
- Efectos que parezcan plantilla.
