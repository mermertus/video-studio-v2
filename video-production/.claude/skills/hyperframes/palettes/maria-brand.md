# Palette: Maria Brand

Palette para HyperFrames y videos de Maria Bejarano.

```css
:root {
  --color-primary: #96BFD4;
  --color-secondary: #C9E1EA;
  --color-accent: #5C1A2C;
  --color-bg: #FDFBF8;
  --color-surface: #F4EEE3;
  --color-text: #241E1B;
  --color-muted: #6E625D;
  --color-border: #E8DED0;
  --color-blue-deep: #4A7691;
}
```

## Uso

- Fondo dominante: `--color-bg` o `--color-secondary`.
- Identidad: `--color-primary`.
- Texto: `--color-text`.
- Datos secundarios: `--color-muted`.
- Accion: `--color-accent`.
