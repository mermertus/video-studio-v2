# Brand Workspace

Version limpia y usable del branding de Maria Bejarano.

Fuente original conservada en:

`../incoming/brand-zip-extracted`

## Archivos principales

- `BRAND-MASTER.md`: manual maestro de marca.
- `voice-and-tone.md`: voz, tono y reglas de escritura.
- `tokens/`: colores, tipografia, espaciado, radios, sombras y movimiento.
- `content-system/`: reglas para carruseles, reels, posts, stories y contenido.
- `hyperframes/`: reglas para adaptar proyectos de HyperFrames a la marca.

## Regla base

El branding manda sobre cualquier referencia externa. HyperFrames puede aportar estructura, ritmo o tecnica, pero la identidad final debe sentirse Maria Bejarano.
